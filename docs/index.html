Cómo usar la app

  1. Activa el servidor FTP de GoldHEN en la PS4.
  2. Conecta el teléfono y la consola a la misma red local.
  3. Escribe la IP de la PS4, usa puerto 2121 y carpeta /data/pkg.
  4. Selecciona tu archivo .pkg y pulsa «Enviar PKG».
  5. Cuando termine, instala el paquete desde Package Installer en la PS4.

Antes de instalar

1. Descarga el APK desde el botón superior.

2. Android puede pedirte autorización para «Instalar aplicaciones desconocidas» desde el navegador.

3. Abre el APK para instalarlo.

El APK está firmado con una clave de depuración para pruebas. Las versiones futuras podrían requerir desinstalar la anterior.

Seguridad: FTP no cifra la transferencia. Úsalo solo en una red local confiable y no abras el puerto FTP a internet.
